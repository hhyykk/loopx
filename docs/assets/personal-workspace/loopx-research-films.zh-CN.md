## 来源与解释

- 研究历程截图的状态条按原计数校正比例：反驳分别占2/133（1.50%）和1/62（1.61%），数字移到条外。这是公开媒体的图表注释，不改变运行中的App或底层研究状态。

- 三维示意解释双方分别接手各自范围，以及研究产物与构建之间的依赖。它采用代码投影，不是 Blender 或物理模拟。实录的软件工程回传与研究历史来自不同案例，不拼接为同一次执行。
- Kanban 和控制项来自公开工作区场景。轨迹分析使用打包 UI 的合成数据；六类过程判断未经科学校准，不产生总分。引用路径为机制示意。
- 历史图记录使用两个 CPU 线程与完整尺寸的生成联合邻域图；在 30% 局部重复条件下，准确率 41.2% → 85.0%。独立边对照的准确率不变、耗时增加 32%。原生分数收益仍未知；这不是 LoopX 与基线的因果对照。
- 复用的 Seedance 2.5 概念镜头保留水印。本次剪辑没有新增远程生成或 benchmark 执行。
- 这是 2.0 开发预览。受众定位不代表已验证企业部署、安全、SLA 或多租户。历史 1.0.3 LHTB 结果保留原版本。

这一版作为后续创作研究的制作基线。固定的是用于比较的作品，不限制之后重新设计叙事、风格、时长或工具；它不是科学 benchmark，也不证明传播收益。早期剪辑保留在 Git 历史中。
